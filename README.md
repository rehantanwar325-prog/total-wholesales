# Total Wholesale

Wholesale ordering storefront built with Next.js - product catalogue and order flow for the Total Wholesale business.

- Live: https://total-wholesales.vercel.app

## Tech stack

- Next.js 16 (App Router, TypeScript)
- React 19
- Tailwind CSS 4

## Getting started

```bash
npm install
npm run dev
npm run build
npm start
npm run lint
```
